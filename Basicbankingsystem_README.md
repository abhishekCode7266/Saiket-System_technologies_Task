# BasicBankingSystem

A simple command-line banking application implemented in Java. This program demonstrates basic account operations such as deposit, withdrawal, balance check, interest application, and transaction history tracking.

Features
- Create a savings account with an initial balance and interest rate
- Deposit and withdraw with validation
- Apply interest to the current balance
- Keep a transaction history for the account

How to compile

```bash
javac Basicbankingsystem.java
```

How to run

```bash
java Basicbankingsystem
```

Usage
- The program runs as an interactive menu. Follow prompts to enter account holder name, initial balance, and interest rate.
- Use the menu to deposit, withdraw, check balance, apply interest, and view transaction history.

Notes
- The program validates amounts (must be positive) and prevents overdrafts.
