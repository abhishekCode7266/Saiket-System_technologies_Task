# Calculator

A simple command-line calculator implemented in Java. It provides basic arithmetic operations.

Features
- Perform addition, subtraction, multiplication and division
- Handles user input and basic validation

How to compile

```bash
javac Calculator.java
```

How to run

```bash
java Calculator
```

Usage
- Run the program and follow on-screen prompts to choose an operation and input numbers.
- Division by zero is handled (depending on program implementation) — watch program messages.

Notes
- If the program expects integer or floating input, provide values accordingly.
