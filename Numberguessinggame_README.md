# Number Guessing Game

A command-line number guessing game implemented in Java. The program picks a random number and the player tries to guess it.

Features
- Random number generation within a defined range
- User guesses with feedback (too high / too low)
- Count attempts and optionally provide scoring

How to compile

```bash
javac Numberguessinggame.java
```

How to run

```bash
java Numberguessinggame
```

Usage
- Follow the prompts to guess the number until you find the correct one.
- The program may display the number of attempts or provide hints.
