# Temperature Converter

A small command-line utility to convert temperatures between Celsius and Fahrenheit (and possibly other scales) implemented in Java.

Features
- Convert Celsius to Fahrenheit and vice versa
- Simple interactive prompts for input and conversion choice

How to compile

```bash
javac Temperatureconverter.java
```

How to run

```bash
java Temperatureconverter
```

Usage
- Run the program and choose the conversion direction, then provide the temperature value when prompted.

Notes
- Ensure to input numeric temperature values. The program may prompt again on invalid input.
