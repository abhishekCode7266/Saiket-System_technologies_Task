# Text File Analyzer

A command-line program that analyzes a text file and provides useful statistics such as word count, line count, character count, and possibly frequency analysis.

Features
- Read and analyze text files
- Provide statistics like lines, words, characters
- May include top words or basic frequency counts

How to compile

```bash
javac Textfileanalyzer.java
```

How to run

```bash
java Textfileanalyzer
```

Usage
- The program may prompt for a file path or expect a filename in the project directory. Provide the path when prompted.
- Check program prompts for supported analysis features.

Notes
- Ensure the file path is correct and the program has read permissions for the file.
