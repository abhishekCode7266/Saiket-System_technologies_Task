# To-do List Application

A simple command-line to-do list application implemented in Java that lets you add, remove, list, and mark tasks as complete.

Features
- Create and store tasks in-memory during program execution
- Add, remove, list, and complete tasks via a menu
- Simple interactive interface using Scanner

How to compile

```bash
javac Todolistapplication.java
```

How to run

```bash
java Todolistapplication
```

Usage
- Run the program and use the interactive menu to manage your tasks.
- Tasks are stored only while the program runs unless the program includes file persistence.

Notes
- If you'd like persistent storage, consider extending the program to save tasks to a file.
